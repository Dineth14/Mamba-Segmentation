# Qualitative Analysis

This folder contains notebooks, figures, and supporting utilities for qualitative inspection of segmentation predictions.

## Contents

- `Mamba Analysis.ipynb` - qualitative visual analysis workflows
- `Mamba Analysis ISPR Postdam.ipynb` - ISPRS-focused qualitative analysis
- `MambaFCS.ipynb` - interactive evaluation and annotation notebook
- `Figures/` - exported figure assets
- `dataset_analysis_LoveDA/` - LoveDA-specific qualitative assets
- `ISPR-Postdam/` - ISPRS qualitative assets
- `mamba-nsst/` - qualitative artifacts for NSST/Mamba variants

## Usage

Open notebooks in VS Code or Jupyter and run them after setting dataset/model paths inside the notebook cells.

## Organization Notes

- This directory stores analysis and visualization assets, not training code.
- Prefer adding new qualitative assets into clear subfolders by dataset or experiment name.
